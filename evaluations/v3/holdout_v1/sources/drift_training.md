# Drift 设计集团培训与验收方案

## 培训安排

管理员共 24 人，分成两个 90 分钟直播班，每班最多 12 人。普通成员共 180 人，先完成异步课程，再参加 30 分钟答疑。项目经理不得用一场大型宣讲替代管理员实操课。

管理员考试及格线为 85 分，最多允许两次补考。因无障碍需求无法完成鼠标操作的学员可以申请键盘操作演示，但评分项目和及格线不变。完成视频播放不等于通过考试。

培训材料提供简体中文和英文版本。管理员指南版本必须为 `ADM-3.2`，普通成员快速指南版本必须为 `USR-2.7`。过期版本可以留档，但不得发给本期学员。

## 业务验收

业务验收需要同时满足以下条件：20 个核心任务中至少 18 个通过；连续 30 分钟观测窗口内 API P95 低于 1.2 秒；严重级别 1 的未关闭缺陷为 0；培训名单完成率至少 95%。四项条件缺一不可。

移动网络测速不计入 API P95，但移动端核心任务仍计入 20 个任务的通过数。严重级别 2 的缺陷可以带书面规避方案上线，但必须明确负责人和修复日期。

最终验收由客户项目发起人签字，培训讲师不能代签。若验收失败，项目保持受限试运行状态，不自动关闭。

## 记录

考试结果和签到记录保存 18 个月；课程录像保存 6 个月。个人无障碍申请只对培训管理员可见，不进入普通项目报告。
